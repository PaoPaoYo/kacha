# Kacha V4 钉图 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 截图确认后可钉在桌面：置顶浮动窗，拖动移动、边缘隐形拖拽等比缩放、hover 显示关闭钮、获焦 ESC 关闭、支持多开

**Architecture:** borderless NSPanel（isFloatingPanel 置顶 + canBecomeKey）承载 SwiftUI PinView；等比 resize 数学集中 PinGeometry 纯函数（TDD）；合成链路复用 V3（裁剪→标注→圆角）。链路：钉图钮 → onPin → CaptureCoordinator 合成 → PinWindowController 开窗。

**Tech Stack:** Swift 6 / SwiftUI / AppKit（NSPanel）

**Spec:** `docs/superpowers/specs/2026-09-18-kacha-v4-pin-design.md`

## Global Constraints

- 钉图按钮：保存钮左侧，SF `pin`（已 probe 存在），24×24 无底色，accessibilityLabel「钉图」
- 等比 resize：无手柄，边缘 hover 出方向光标（内 8pt 边缘区；四边直向/四角对角），拖动等比（锚定对边/对角）；最小 64×64、clamp 屏内
- 关闭钮：默认隐藏，鼠标移入窗口显示（右上角液态玻璃小圆钮，`xmark`）；点击关闭释放
- ESC：窗口为 key（点击钉图获焦）时关闭
- 多开：每次钉图独立 NSPanel，互不干扰；app 终止全清
- 初始尺寸 = 选区 point 尺寸 clamp 屏内；内容 = 最终合成图（标注+圆角）
- 提交信息：中文 + Conventional Commits 前缀，末尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`
- 既有 49 测试不得回归

### Task 1: PinGeometry 等比缩放纯逻辑（TDD）

**Files:**
- Create: `Sources/Kacha/PinGeometry.swift`
- Test: `Tests/KachaTests/PinGeometryTests.swift`

**Interfaces:**
- Produces: `enum PinGeometry { static func edge(at:in:) -> PinEdge?; static func resized(from: CGSize, by: CGSize, edge: PinEdge, aspect: CGFloat, minSize: CGSize, bounds: CGSize) -> CGRect }`
  - `enum PinEdge { case topLeft, top, topRight, right, bottomRight, bottom, bottomLeft, left }`（+ 判定函数：点在 rect 边缘 8pt 内返回对应边/角，内部返回 nil）
  - `resized`：以 edge 的对边/对角为锚点，拖动量按主轴换算等比尺寸（aspect = w/h），clamp min 64 与屏内，返回新窗口 frame（锚点不动）

### Task 2: PinWindow 体系与全链路接线

**Files:**
- Create: `Sources/Kacha/PinWindow.swift`（PinWindowController + PinPanel + PinView）
- Modify: `Sources/Kacha/SelectionView.swift`（钉图钮 + onPin 签名扩展）
- Modify: `Sources/Kacha/OverlayController.swift`（onPin 透传 + handleConfirm 增 .pin action）
- Modify: `Sources/Kacha/CaptureCoordinator.swift`（.pin 分支：合成 → PinWindowController）

**Interfaces:**
- Consumes: `PinGeometry`（Task 1）；V3 合成链（AnnotationRenderer/圆角化）；现有 onConfirm/onSave 闭包模式
- Produces: `@MainActor final class PinWindowController { static let shared; func pin(_ image: CGImage, pointSize: CGSize); func closeAll() }`；`CaptureAction` 增 `.pin` case

**规格（精确）**：
- **PinPanel**：borderless NSPanel、`isFloatingPanel = true`、`canBecomeKey = true`（override）、`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`、`isOpaque = false`、`backgroundColor = .clear`、`level = .floating`、`hidesOnDeactivate = false`；contentView = NSHostingView(PinView)
- **PinView**：最终图（Image resizable 按窗口尺寸）；`onContinuousHover` 边缘判定（PinGeometry.edge，内 8pt）切光标（复用方向光标逻辑：四边 resizeLeftRight/UpDown、四角 frameResize 或 NSCursor 系统 resize）；拖动手势——边缘起拖 = 等比 resize（窗口 setFrame），内部起拖 = 移动（setFrameOrigin，注意边界 clamp 屏内可出）；hover 显示右上关闭钮（16pt 玻璃圆钮 xmark，点击 close 并从 controller 移除）；`.onExitCommand { close }`（key 时 ESC）
- **PinWindowController**：windows 数组；pin() 计算初始 frame（pointSize clamp 屏内、置于选区原位置附近或屏中）、makeKeyAndOrderFront；窗口关闭回调移除引用；`closeAll()` 供 app 终止（KachaApp applicationWillTerminate 调用）
- **接线**：SelectionView 钉图钮（保存钮左）调 `onPin(selection, CGFloat(cornerRadius), annotations)`（守卫同 confirm/save）；OverlayController onPin 闭包走 handleConfirm(action: .pin)；CaptureCoordinator `.pin` 分支：合成（同复制链路）→ `PinWindowController.shared.pin(image, pointSize: pointRect.size)` → Tink
