# 标注对象编辑设计

## 目标

在截图标注会话内，为箭头、矩形、椭圆和画笔提供选择、删除、整体移动、颜色/线宽修改和形状二次编辑；所有编辑操作支持撤销与重做。模糊标注维持现有创建后不可编辑的行为。

## 范围

### 支持的对象

| 类型 | 选择与移动 | 样式编辑 | 形状编辑 |
| --- | --- | --- | --- |
| 箭头 | 整体移动 | 颜色、线宽 | 独立拖动起点和终点 |
| 矩形 | 整体移动 | 颜色、线宽 | 四角和四边八个手柄调整大小 |
| 椭圆 | 整体移动 | 颜色、线宽 | 四角和四边八个手柄调整宽高，不锁定比例 |
| 画笔 | 整体移动 | 颜色、线宽 | 不支持逐点编辑或缩放 |
| 模糊 | 不支持 | 不支持 | 不支持 |

标注仍只在当前截图 overlay 生命周期内可编辑；确认、复制、保存或钉图后，输出仍是合成后的位图。

## 交互

### 选择与手势优先级

在选择工具中，鼠标命中优先级固定为：

1. 已选标注的控制点；
2. 顶层可编辑标注的路径或可移动区域；
3. 截图选区的八个缩放手柄；
4. 截图选区内部的移动操作。

点击空白处取消标注选择。切换到任一创建工具时也取消标注选择。正在创建的临时标注不可被选择。

矩形和椭圆只通过边线命中，内部空白不会被误选。箭头和画笔按实际描边命中，命中容差随线宽扩展。命中多个重叠标注时，数组末尾的顶层标注优先。

### 编辑视觉与光标

选中态仅显示在 SwiftUI 预览层，不进入 `AnnotationRenderer` 或最终输出：

- 箭头显示首尾两个圆形控制点；
- 矩形与椭圆显示边界框及八个控制点；
- 画笔显示边界框但没有缩放控制点；
- 拖动控制点使用对应方向 resize 光标；拖动对象使用 closed-hand 光标；箭头端点使用 crosshair 光标。

### 样式与删除

颜色和线宽控件在选中可编辑对象时读取并修改该对象；无对象选中时继续设置下一笔新标注的默认样式。选中对象显示删除动作，`Delete`/`Backspace` 删除对象；没有对象选中时删除动作不可用。模糊对象不进入选中编辑流程，避免显示无效颜色控件。

### 历史

历史记录包含完整的标注文档和当前选择：

```swift
struct AnnotationDocumentState {
    var annotations: [Annotation]
    var selectedAnnotationID: Annotation.ID?
}
```

创建、删除、颜色、线宽、整体移动、箭头端点调整和矩形/椭圆调整都进入操作级历史。拖拽只在松开时生成一条历史记录。`⌘Z` 撤销，`⌘⇧Z` 重做；任何新操作发生后清空 redo 栈。

## 架构

### 纯逻辑编辑层

新增不依赖 SwiftUI/AppKit 的编辑模块，围绕既有归一化 `Annotation` 模型提供：

- 可编辑对象的命中测试、可见 bounds 和控制点；
- 以标注 ID 为键的替换、删除和样式更新；
- 归一化坐标下的平移、箭头端点调整、矩形/椭圆八向 resize、画笔点集平移；
- 边界 clamp、正尺寸矩形归一化和最小交互尺寸；
- 快照式 undo/redo。

`AnnotationRenderer` 继续只负责最终位图合成。编辑辅助线与手柄由 `SelectionView` 预览 overlay 独立渲染。

### SelectionView 适配

`SelectionView` 维护选择 ID、当前编辑操作、拖拽起点与编辑前快照。它把鼠标事件按既定优先级路由至编辑层或现有截图选区调整层，并将样式工具栏绑定至选中对象或新建默认样式。现有创建工具和截图选区交互应保持可用。

## 测试策略

先为纯逻辑层建立 XCTest 覆盖：

- 顶层命中、描边容差、空心形状内部不命中；
- 箭头端点与整体平移；
- 矩形/椭圆八个 resize 手柄、交叉拖拽和边界 clamp；
- 画笔整体平移；
- 按 ID 删除与样式更新；
- undo/redo、拖拽单步提交和新操作清空 redo。

随后补 renderer 回归测试，验证编辑后的箭头、椭圆、画笔以及多笔顺序仍正确导出。最后进行人工 smoke 测试，覆盖手势优先级、控制点、键盘删除、颜色/线宽和撤销/重做，确认导出不包含选中辅助视觉。
